## Design Context

### Users
Neovim users evaluating an editor integration for Codex, Antigravity, or Cursor CLI. They need to see the workflow, install the plugin, and find configuration details.

### Brand Personality
Focused, practical, understated. Use precise English copy consistent with the README.

### Aesthetic Direction
Initial working direction: a restrained dark project page that complements the existing Tokyo Night terminal captures. Use large editorial headings, flat sections, real product images, and warm coral accents. This direction is a default pending any user preference.

### Design Principles
- Show real plugin behavior and avoid invented product claims.
- Make installation and documentation easy to find.
- Keep the site static and dependency-free for GitHub Pages.
- Support mobile layouts, keyboard use, visible focus, and reduced motion.
